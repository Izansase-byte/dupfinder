# Dupfinder

It is CL tool that searches duplicates.

## Features

- Directory scanning
- File grouping by size
- Duplicate file detection
- Recoverable disk space calculation.

### Available commands

| Command | Description |
|---------|-------------|
| `dupfinder <directory>` | Scan a directory |
| `dupfinder --help` | Display help |
| `dupfinder --version` | Display version |
| `dupfinder` | Scan the default `test` directory |
